# 分析、取舍与覆盖

充分阅读正文与相关技术附录，再沿 Abstract → Method → Experiment → Discussion 提炼。阅读范围可以很广，输出范围由核心问题和每页 10 分钟预算决定。

## 论文身份与摘要

记录固定版本的英文原文 Abstract，仅修复断行、连字符等提取瑕疵，不翻译或润色。固定 PDF 为图号、公式和页码基准。

完整记录作者顺序、原文给出的共同贡献/通讯标记及单位对应，不推测现职。用正式论文页、会议/期刊记录核实发表状态，区分本次阅读版本与正式发表情况，记录核查日期。

核对项目页、代码、权重、数据、演示、博客、视频、补充材料的归属与用途；官方和第三方区分标明。没有的资源不凑链接，失效出处显式标注。

## 先决定保留什么

把原文各项信息放入四类，不按原段落数量分配篇幅：

| 处理 | 判据 | 输出 |
|---|---|---|
| 核心必讲 | 影响问题、创新、机制、主要证据或边界 | 主页面就近解释，不能仅给外链 |
| 合并概述 | 多项实验或细节共同回答同一问题 | 保留共同结论、代表数值及例外 |
| 可选深入 | 独立问题值得深入，但不阻断核心理解 | 仅在需要时形成补充页，每页也 ≤10 分钟 |
| 不展开 | 不改变核心判断的历史、重复结果、参数或证明细节 | 覆盖记录写原因及原文定位 |

Method/Experiment 保留原论证顺序，可合并相邻或回答同一问题的小节；用原节号追溯，不强制照搬标题。原引言、相关工作、结论与附录中的重要信息应吸收进主线，剩余内容可有依据地不展开。

建议起稿约 1400–2200 中文字，另加原文英文 Abstract、少量关键图表和必要公式；这只是起点，最终以实际时间估算和理解检查为准。通常 Method 占最大篇幅，Experiment 与 Discussion 都保留实质内容；不规定机械字数比例。

## 从复述转为提炼

每个核心贡献组织成：**问题 → 改动 → 作用机制 → 证据 → 边界**。网页不必逐项列标签，但链条应成立。

- Method：先说关键改动，再解释如何工作，指出继承部分。展开决定贡献的步骤，压缩标准模块的教材介绍。
- Experiment：一个研究问题用一段或一行比较表回答；关键数值和比较条件一起出现。不同任务的主要证据不能混成“全面领先”。
- Discussion：说明哪些证据足够、哪些比较有混杂；能力以何种输入、数据或成本为代价；对应用/后续研究有何具体启发。推断要有前提，不照抄作者展望。

例：不能只写“加入几何分支后指标提高”。应交代在什么相同设置下提高、消融隔离了哪个变量、为何这与所提机制相符，以及为何仍不能排除其他解释。保留足以支撑这个判断的数值，不复制整表和全部实验设置。

## 覆盖记录

`coverage.json` 保存原节名、编号、图表/页码、优先级、处理及原因。正文精简不意味着分析只读摘要。

```json
{
  "source_version": "固定论文版本",
  "items": [
    {
      "kind": "section",
      "source": "§3.2, PDF p.5, Eq.10–12",
      "question": "匹配目标与几何目标怎样配合？",
      "priority": "core",
      "target": "method-loss",
      "status": "explained",
      "note": "保留两个目标的作用与关键定义，合并重复推导"
    },
    {
      "kind": "appendix",
      "source": "附录中的非核心实现细节",
      "priority": "optional",
      "status": "reference-only",
      "note": "不影响核心机制判断；本页不展开逐参数复现"
    }
  ],
  "gaps": []
}
```

类型可含 abstract、section、contribution、equation、experiment、ablation、limitation、appendix。状态：
- `verbatim`：已校对的原文摘要。
- `explained` / `summarized`：本页解释或合并概述，必须有 target；摘要式处理写清保留与省略。
- `linked`：实际存在的补充 HTML，target 使用 `detail.html#anchor`，写明其独立问题；核心主张仍在主页面成立。
- `reference-only`：有意不展开，必须给原文 source 与理由，不能用于回避 core 项目。
- `not-applicable` / `unresolved`：不适用或材料不足；后者说明影响。

技术附录中决定主线正确性的假设、训练条件或反例提升为 core；不是所有附录都必须另写一遍。覆盖“阅读过”与“输出每项细节”是两回事。

## 方法与公式

主页面必须能追踪输入 → 关键中间表示 → 输出，说明已知/预测/优化的量、关键单位或参考系。几何论文尤其注意相机、尺度、坐标系、metric 的依据；其余学科检查对应测量和假设。

只选理解贡献不可缺少的公式。每个公式交代用途、必要符号、为何是这个形式以及关键假设。影响理解的推理就近解释，完整代数推导、小例子、一般教材内容按需要取舍。不能仅报 loss/attention/PnP 名称，也不默认逐项展开所有 loss 的梯度、所有采样参数。

区分训练与推理，说明决定行为的数据、监督、初始化与后端；学习率、batch、停止条件等只在影响核心判断或本页主题是复现时详细展开。理论论文保留假设、关键定理与证明思路，不能把直觉写成完整证明。

## 实验证据

主实验族各有结论，选足够支撑判断的原始数值和代表对照，并给出处：

- 它检验哪个问题，主要比较条件与差异是什么？
- 指标测量什么、单位与方向是什么？相同缩写不能跨任务直接类比。
- 什么被控制、什么可能混杂？受控消融比跨论文排行榜更能支持归因。
- 支持与不支持什么，是否存在反例、失败、无收益或成本增加？

把统计单位、真值/预测输入、有无优化、不同数据与分辨率、不同 checkpoint 等影响可比性的条件保留在对应结果旁。原文未给不确定性就不补造。图表精选，不逐行转写排行榜；对同类结果概述趋势和例外。

## 讨论与进一步阅读

至少形成两个有依据的判断，分别连接具体设计或实验。可讨论“哪项创新更有迁移价值”“哪些设置限制结论外推”“什么成本决定是否值得采用”。区分作者限制与本页推断，不用笼统优缺点清单替代分析。

完整复现配置、长证明和历史脉络通常留原文定位；只有确有独立学习价值时增加专题页。代码核查只说明真正读过的 revision，不能用当前默认值替代历史论文。主页面须自行解释核心内容；补充页是深入选项。
