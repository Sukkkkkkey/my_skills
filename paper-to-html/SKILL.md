# 单篇论文 → 10 分钟提要、精炼与讨论

产物是一份经过取舍和分析的论文阅读稿。正文默认中文，**摘要区仅展示论文英文原文 Abstract**。读者熟悉领域基础，但不默认掌握论文特有的符号、模块或推导。默认每个网页预估阅读时间不超过 **10 分钟**，以 8–9 分钟留出理解余量。沿用用户明确指定的其他时间、语言和深度。

默认阅读顺序：**论文信息 → Abstract → Method → Experiment → Discussion → 必要补充**。保留论文的论证主线；Method/Experiment 可合并同一问题的原小节，以原节号标注来源，不要求把论文目录逐节复刻。不要在英文摘要前添加自编摘要。

验收标准：读者仅凭本页能说明**解决什么问题、真正改变了什么、核心机制如何工作、证据支持到哪里、代价与适用边界是什么**。主线中解释不可缺少的符号和推理；完整证明、全部超参数与逐项复现流程不作为默认单页承诺。“全面”指核心问题覆盖与论证完整，不指转述每段原文，也不承诺 10 分钟掌握全部实现细节。

除英文 Abstract 和必要短引文外，以自己的话提炼。每段承担一个解释或判断，删除跨章节重复贡献、逐句翻译、无解释的数据罗列和泛泛评价。Discussion 是必需内容，不能为压缩篇幅而删去；保留至少两个有具体证据或明确前提的判断，区分作者报告与本页分析。

## 执行路线

### 1. 固定论文与学习范围

- 确认标题、完整作者顺序、作者与单位对应、论文类型、版本、正文和附录。单位以论文发表时的署名为准，不用作者现单位替换。固定 PDF 为摘要、公式、图号、表号、页码的基准；PDF 物理页与印刷页分开标注。
- 核实发表情况：预印本 / 已接收 / 已发表、会议或期刊、年份、正式论文页与 DOI（若有）。用官方会议/期刊记录核实，区分首次预印本日期与正式发表年份；未知项写“未核实”，不能由 arXiv 编号推断已发表。
- 搜集并打开核实相关入口：Paper/PDF、Project page、Code、Model/Weights、Dataset、Demo、Blog、Video/Slides 等。优先官方来源；第三方解读显式标注。只展示存在且确认指向该工作的链接，不猜 URL、不凑齐不存在的资源。页面首屏集中展示论文身份与链接，详细来源及核查日期留在来源区。
- 用户给出 PDF 时只读原文件。保存来源、版本和 SHA-256。新版本或代码仅在确有需要时补查，并记录差异。评测数字以所选版本为准。
- 正文和补充材料可获得时先读完整结构，再深入关键段落。只拿到摘要、损坏公式或缺失补充材料时，继续可做部分并具体列出缺口，不把不完整材料写成全面精读。
- 按任务组织内容。方法论文讲算法与消融；理论论文讲假设、定理、证明依赖与反例；数据/基准论文讲构造、标注、划分、指标和偏差；分析论文讲探针、干预和因果解释边界。不要为没有训练的论文硬造训练章节。

### 2. 先建覆盖与证据记录，再写正文

阅读 [分析与覆盖规范](references/analysis.md)。建立 `coverage.json`，登记正文与技术附录的处理方式；核心贡献、必要公式、主要实验与限制映射到 HTML 锚点，合并或不展开的细节写明取舍理由与原文定位。

每个核心结论记录：结论文本 → 原文位置 → 支持证据 → 适用条件。区分原文报告、解释性推导、本页分析和未证实猜想。不能只读摘要、架构图和排行榜就开始总结。

先读充分，再写精简。将内容分为“核心必讲 / 合并概述 / 可选深入 / 不展开并说明原因”。图表选择能支撑机制、主要结论、消融或边界的少数关键证据，通常 2–4 张即可，不按数量凑图。多个实验回答同一问题时合并讲；不能省略会改变结论的负面结果、关键条件或附录事实。覆盖记录保留所有取舍，网页不承担逐节搬运任务。

### 3. 按论文逻辑精炼，并加入讨论

主线层默认按以下次序呈现。先确定每节希望读者记住的结论，再选择必要解释与证据；细节的保留取决于它是否改变对机制或结论的理解。

1. `abstract` — **Abstract**：展示固定版本的英文原文摘要，默认展开；不附中文译文，不用自写英文摘要或中文中心思想替代。校对 PDF 提取的断行、连字符和数学符号，保留原意与段落，附来源位置。遵守原文复用条件；只能展示节选时明确标注节选并链接全文，不冒充完整原文。
2. `method` — **Method / 方法**：开头用一两句提炼问题与核心改动，再沿原方法逻辑串起输入、关键设计和输出。明确继承与新增；把“做了什么、为何这样做、相对基线改变什么”讲在一起。只保留理解贡献必需的公式和符号，通常 1–3 个；训练与推理的角色、输入假设及决定行为的细节不能丢。
3. `experiment` — **Experiment / 实验**：沿原实验逻辑按研究问题合并证据，用少量代表数值说明提升、消融归因与限制。主实验族各有概述，不逐行抄榜单；交代足以判断可比性的输入、数据、指标与计算条件。失败、成本和不支持预期的结果同样保留。
4. `discussion` — **Discussion / 讨论**：提炼相对最近基线的新意、证据的强弱、能力与成本的交换，以及适合/不适合的使用条件。至少两个具体判断，每个都能指向证据或清楚标出的推断前提；不把原 Conclusion 换词当作讨论。

之后仅补充确有价值的背景、小例子或自测，不默认铺开历史、全部附录、复现清单与长问答。引言与相关工作的关键定位、结论与附录中影响判断的事实，吸收进上述主线；其余记录原文定位即可。阅读稿的取舍规则见 [分析与覆盖规范](references/analysis.md)。

保留已有专题引用的旧锚点；合并内容时用兼容锚点指向对应解释，拆页时留下明确链接。必须深入的长推导可成为有独立问题的补充 HTML，主页面先给结论与必要直觉。补充页也默认不超过 10 分钟，禁止靠折叠或机械拆分页掩盖冗长。补充页围绕自己的问题组织，只需标明论文与返回主页面的入口，不重复整段 Abstract 和已有主线。

理论论文或没有实验的论文沿用真实章节（如 Theory / Proof / Analysis），不捏造实验。时间紧时先删重复、合并同类证据、后移非核心推导；不能删掉理解主线所需的定义与限定条件。用户明确要求更长精读时才改变默认预算。

### 4. 原图和公式形成可检查的证据

- 从原 PDF 裁切关键图表，保留完整坐标轴、图例、表头、单位、脚注及相关行；细节太密时另给完整图与局部放大。裁切后逐张目视检查。
- 每处图表说明“看什么 → 怎么读 → 观察到什么 → 支持哪项结论 → 条件/例外”。必须区分数据分组、数值单位、百分比与百分点、基线配置、真值/预测输入及对齐方式。
- 来源写清版本、原图/表号、PDF 物理页及本地/官方链接。自主绘制的示意图显式标为重绘，不冒充原图。图号以 PDF 为准，不能直接相信网页解析编号。
- 关键公式可用原公式裁切辅助核对，正文解释它计算什么、符号含义及为什么影响结果；只展开主线不可缺少的推理。复杂数学使用本地渲染资源或 MathML；不能留下未渲染的 LaTeX。发现疑似符号/排版错误时对照原页和可用官方实现，分别注明原文写法与解释性改写，不悄悄修正或声称已核对未读的代码。

### 5. 构建可连续阅读的离线页面

默认交付一个独立目录中的 `index.html` 与相对路径资源；“独立阅读”不等于必须将所有图片塞进单一文件。用户明确要求单文件时再内嵌。

推荐附带的生成器及蓝灰阅读样式。已有页面保持其风格与稳定锚点；不要强制重建网站或发布。

- 阅读 [构建与数据约定](references/build.md)，使用 `scripts/build_study.py`。正文自由撰写；脚本只组织导航、引用和图表，不替代论文分析。
- `scripts/paper_assets.py` 提取页文本、渲染页面、裁切并记来源。使用环境现有 PDF 工具亦可，保留同等可追溯信息。
- 正文约 70–85 字符宽，清晰层级，方法流程与证据靠近。长表横向滚动、移动目录、图表放大、可展开推导、自测答案和打印样式；基础内容在关闭 JavaScript 后仍可读。
- 页首显示实际计算的“预估阅读约 N 分钟”。摘要、正文、图注、图表理解、公式和折叠内容均计入预算；来源目录和导航不计。时间估算是编辑检查，不是对读者实际用时的保证。估算方法及工具见 [构建与数据约定](references/build.md)。
- 不把核心讲解藏在折叠中。折叠只用于短答案等次要内容，不能规避时间限制；页面开头避免大面积空白、宣传式标题和无意义装饰。

### 6. 自审、修订、再验收

使用 [阅读稿质量审查](references/review.md)，分开检查来源事实、提炼与讨论、实际可读性。先核对英文摘要、作者单位、发表与资源，再检查每个段落是否提供解释或判断，以及重要取舍是否改变结论。记录发现、修正和残留缺口。

运行 `scripts/validate_study.py <output/index.html>` 检查结构和阅读预算；超时就精简后再检查，不能手填“10 分钟”或提高阅读速度参数凑过关。浏览器可用时用 `scripts/qa_browser.mjs` 或等效工具验证桌面和手机，并实际查看截图。复杂图表须人工增加理解时间；自动检查不能证明内容已准确或精炼。

做“仅 HTML 闭卷检查”：复述问题、创新、机制、关键证据、代价与边界；只用 HTML 回答，再回原文核查。六项核心问题必须闭环，不能靠增加引用链接补缺。审查问答保存在记录中；网页至多选 2–3 个短自测并计入时间，不默认展示整套题库。

## 完成与边界

交付 HTML 链接，简述覆盖、主要图表与验证；仅报告实际做过的检查。来源记录与审查记录留在输出目录。已说明的假设不重复询问；不因该 skill 自动改原始笔记、上传论文、推送 Git、安装模型或发表内容。用户已经授权的相关动作按会话范围继续。

本 skill 自带工具无个人路径、API 密钥或领域专用常量；机器学习/3D 的例子是审查线索，不限制其他学科。
