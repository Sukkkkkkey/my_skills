# 实验结果记录

让读者快速看清每项实验的目的、配置差异和结果，并能追溯证据。以下为默认约定，用户指定的模板和流程优先。

## 布局

- 一个主 sheet 记录所有实验；每个定量实验另有一个逐样本 sheet。定性实验默认只在总览记录，不另铺配置、运行和日志等技术 sheet。
- 总览每行对应“方法/结构 × 实际配置 × seed 或重复策略”；明细每行再加样本维度。多个 seed 可以分别展示，也可按明确协议聚合。
- 一个实验 ID/名称只占一个纵向合并单元格，覆盖其比较行；研究目的、总览数据范围及总体结论同样合并。明细中的样本标识仅跨自身比较行合并。
- 所有 sheet 保持一致的列组顺序、表头层级、术语和样式。列组横向合并；定量组下按评价协议排列指标，并标明单位与优劣方向。

| 列组 | 内容 |
| --- | --- |
| 实验信息 | ID/名称、研究目的或改动、数据范围；明细显示样本 ID |
| 方法与配置 | 方法/结构、关键参数、seed/重复策略、运行与评估进度 |
| 定性结果 | 总体结论、各配置或样本的观察与限制 |
| 定量结果 | 各协议的有效数/总数及具体指标 |
| 证据链接 | 完整配置、结果目录、分析报告 |

主指标默认可见，次要指标可折叠。冻结表头与主要标识，设置换行和合理列宽；合并区按实验/样本成组，不能单行跨组排序。完整分析放在链接报告中。

## 配置与结论

- 写实际参数值，不仅写“default”或配置名；数据版本/split、代码、权重和环境记录可通过完整配置链接追溯。缺失配置标为“未知”。
- 随机实验记录 seed 值/集合、作用阶段及重置或复用策略。同名配置但有效参数不同必须分开；无关路径、时间戳或环境哈希变化不自动构成新配置。
- 默认只记本项目实际结果；用户明确要求的外部参考值另标来源。区分运行完成、评价完成和分析完成，补充实验如实纳入，重试不计为新 seed。
- 总体结论简写一次，配置差异逐行写。区分观察、指标支持的结论与经对照验证的原因；没有 GT 的定性实验不编造准确率，未分析的结果不借用已有结论。

## 指标口径

- 从实际逐样本结果重算汇总，检查重复记录、有限数值、单位、协议与样本数。旧表和计划文件不能覆盖新增已完成结果；数值不一致时追溯原因。
- **零值、执行失败、指标失败、待评估、不适用和缺失分别表示。** 每组指标的有效数和分母含义明确；有效集合不同的指标不能共用误导性的计数。不把失败填为零，不静默丢弃样本或新增指标。
- 不混合调试集与正式集或不相容的评价协议。明确按样本、视图、seed 等哪一层聚合、如何加权及标准差约定；保存数值精度，在显示层舍入。
- 方法有效样本集合不同时显示各自覆盖率；配对比较另算所比较方法的共同有效集合，并列交集大小。交集不能用最小有效数代替，也不能借用无关方法的集合。

## 刷新与核验

1. 读取现有工作簿与实验来源，识别人工结论、备注和报告链接。总体内容按实验 ID 保留；逐行内容按“实验＋样本/汇总范围＋方法＋实际配置＋重复策略”映射，不能依赖行号。合并单元格先展开逻辑值再迁移。
2. 区分自动内容和人工编辑。身份变化存在歧义、已有实验暂时缺失或遇到未知 sheet 时，保留原内容并说明；仅移除已授权删除的冗余内容。记录整理不包含重跑实验或修改原始结果。
3. 写临时工作簿，读回检查数值类型、数量、合并区、链接和人工内容；从来源独立核对汇总与缺失状态，再替换原文件。有并发写入时加锁或检查版本，避免覆盖新编辑。
4. 结构调整提供代表性区域预览，检查长结论、主指标和缺失状态是否清晰。用户要求先审阅时先交付草稿；普通更新不追加审批。说明核验范围和未解决项，审计细节留在表外，清理本次临时副本。
